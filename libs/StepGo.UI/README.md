# StepGo.UI

Shared design system (Razor Class Library) for all four StepGo apps: design
tokens, breakpoints, and the core component library (Button, Card, Table,
StatusTag, StepIndicator, OwlTip, Wizard).

## Rebuilding the CSS

`wwwroot/css/app.css` is generated by the Tailwind CLI from `Styles/input.css`
+ `tailwind.config.js`, and is committed so `dotnet build`/`dotnet run` work
without requiring Node. After editing either input file, regenerate it:

```bash
npx --yes tailwindcss@3 -i ./Styles/input.css -o ./wwwroot/css/app.css
```

**Do not** wrap custom rules in `@layer base` / `@layer components` in
`Styles/input.css` — with this Tailwind CLI version, content globs that match
`.razor`/`.cshtml` files cause anything inside a `@layer` block to be
silently dropped from the output (utilities from `@tailwind utilities` are
unaffected). Plain CSS placed between the `@tailwind` directives works
correctly and keeps the same effective cascade order.
